# Российский хостинг: что подходит и что бесплатно

Обзор сделан 22 августа 2026. Условия акций провайдеры меняют часто — перед
заказом сверьтесь с их сайтом.

## Чего требует CorNet от площадки

Это не сайт, а долгоживущий Node-процесс, и это сужает выбор сильнее, чем кажется:

- **WebSocket без таймаута.** Лента сообщений и сигналинг звонков (`server/src/ws.js`)
  держат соединение открытым. Виртуальный (shared) хостинг обычно рвёт его по
  таймауту прокси — поэтому нужен VPS с root, а не «хостинг для сайтов».
- **PostgreSQL 16.**
- **Постоянный диск для `/data/uploads`.** На Railway два деплоя уже стирали аватарки:
  файловая система контейнера одноразовая. На VPS диск и так постоянный.
- **Порты 80/443 наружу** для Let's Encrypt и HTTPS. Без HTTPS не работают ни
  `getUserMedia`, ни Service Worker, ни Web Push.
- **Минимум 1 ГБ RAM, лучше 2.** Node + Postgres + nginx в 512 МБ живут впритык.

Отсюда главный вывод: **бесплатные предложения виртуального хостинга не подходят**,
нужен VPS.

## Что реально бесплатно

| Провайдер | Что дают | Карта | Годится? |
|---|---|---|---|
| **Timeweb Cloud** | тестовый период 3 дня + приветственный грант 300–500 ₽ на счёт | да, привязка | **да** — полноценный VPS с root |
| **RUVDS** | 3 дня теста, любая конфигурация до 3000 ₽ | да, через Paymaster | **да**, но списание автоматическое |
| **Selectel** | грант до 30 000 бонусов на 30 дней | нет | **нет для физлиц** — грант только юрлицам и ИП |
| **Beget** | 30 дней виртуального хостинга бесплатно, без карты | нет | **нет** — Node там под Apache mod_passenger, WebSocket не гарантирован; у VPS теста нет |
| **AdminVPS** | 5–7 дней по запросу в поддержку | обычно нет | да, но период выдаётся вручную |

### Рекомендация

**Timeweb Cloud.** Единственный из списка, где физлицо получает настоящий VPS
с root бесплатно и без переписки с поддержкой: грант 300–500 ₽ при тарифе
от 590 ₽/мес покрывает примерно 15–25 дней на минимальной машине при почасовой
тарификации. Дальше сервер под этот мессенджер стоит порядка 400–600 ₽/мес.

**RUVDS** — запасной вариант, если у Timeweb грант не дали. Помните про
автосписание: сервер нужно удалить до конца третьих суток, иначе спишут деньги,
а при их отсутствии сервер заблокируют и удалят вместе с данными.

**Selectel** имеет смысл, только если разворачиваете от ИП или ООО — там условия
лучше всех остальных: 30 000 ₽ на 30 дней, карта не нужна. Грант выдают по тикету
с описанием проекта, решение до 5 рабочих дней.

## Развёртывание на VPS

Всё уже готово в `deploy/`: три контейнера (приложение, Postgres, nginx с
Let's Encrypt), данные в томах на хосте. Подробности — в `deploy/README.md`.

```bash
# на свежей Ubuntu 24.04
curl -fsSL https://get.docker.com | sh
git clone <репозиторий> cornet && cd cornet/deploy
cp .env.example .env && nano .env      # DOMAIN, пароли, ключи
docker compose up -d --build
```

Домен на VPS нужен обязательно — Let's Encrypt не выдаёт сертификаты на голый IP,
а без HTTPS мессенджер не заработает. Домен в зоне `.ru` стоит около 200 ₽/год.

После переезда мобильные приложения надо пересобрать: адрес сервера зашивается
в бандл на этапе сборки, а не читается из настроек.

```bash
VITE_API_URL=https://ваш-домен npm run build
npm run android:apk
```

## Что не забыть на новом сервере

- **TURN-сервер.** Его нет и сейчас: при строгом NAT с обеих сторон звонок не
  установится. На своём VPS это лечится своим coturn — см. «Настройка TURN-сервера»
  в README.
- **`APP_ORIGIN`** должен точно совпадать с адресом, иначе CORS отрежет клиента.
- **Бэкап `./data`.** Это и база, и все загруженные файлы. Снапшоты диска у
  провайдера обычно платные и почасовые — дешевле `pg_dump` по крону в S3.
